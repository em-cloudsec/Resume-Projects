# Audit Scripts – AWS Environment Security Audit

This folder contains scripts used to perform a security audit across core AWS services.

Planned audit coverage:

- IAM (users, groups, MFA, access keys, policies)
- Security Groups (inbound/outbound rules, open ports)
- VPC (subnets, ACLs, routing)
- EC2 (instance security posture)
- CloudWatch (metrics and alarms)
- CloudTrail (trail configuration and logging status)

Current files:

- `audit-env.py` – placeholder for a Python-based environment audit script.
