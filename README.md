# Cloud Security & AWS Engineering Portfolio

This repository showcases hands-on AWS cloud security projects designed to reflect real-world skills for Cloud Security Engineer and Cloud Engineer roles.

## Projects

1. **Secure AWS Account Baseline**  
   Hardens the AWS root account, implements IAM best practices, and enforces strong credential policies.

2. **Secure VPC Networking**  
   Designs and analyzes a multi-tier VPC with public/private subnets, NAT, routing, and segmentation.

3. **CloudTrail & Security Hub Monitoring**  
   Enables centralized logging and security posture management across regions.

4. **Incident Response – EC2 Quarantine Automation**  
   Uses SSM Automation and security groups to isolate compromised EC2 instances.

5. **AWS Environment Security Audit**  
   Performs a structured audit of IAM, SGs, VPC, EC2, CloudWatch, and CloudTrail.

Each project folder contains:
- A `README.md` explaining architecture, purpose, and validation.
- (Planned) Terraform IaC definitions to make deployment reproducible.
- Evidence (logs, findings, screenshots) that the environment was configured and tested.
