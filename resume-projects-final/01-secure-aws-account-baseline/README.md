# Secure AWS Account Baseline

## Purpose
Establish a hardened AWS account foundation through IAM least privilege, MFA enforcement, and credential policy controls.

## Acronyms Used
- IAM: Identity and Access Management
- MFA: Multi-Factor Authentication
- ARN: Amazon Resource Name

## Evidence
See the iam/ folder for the following:
- admin-policy.json
- readonly-policy.json
- password-policy.json
